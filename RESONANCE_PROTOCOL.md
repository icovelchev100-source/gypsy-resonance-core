## 3. ИМПУЛС (EMIT)

```python
emit(source: str, marker: str, data: Any)
```

### Структура на импулса

```json
{
  "source": "Matrix",
  "marker": "TOFU::1",
  "data": {"coherence": 0.6312},
  "phase": 0.034,
  "timestamp": 1723912345.123,
  "signature": "a1b2c3d4"
}
```

### Процес

1. Слой излъчва импулс
2. Импулсът се регистрира в история
3. Импулсът се разпраща на всички останали слоеве
4. Фазите се синхронизират

---

## 4. СИНХРОНИЗАЦИЯ (BROADCAST)

### Логика

```python
for each_layer in layers:
    if layer == impulse_source:
        continue  # Пропусни източника
    
    phase_diff = abs(layer.phase - impulse.phase)
    
    if phase_diff < THRESHOLD (0.05):
        # Малка разлика → лека синхронизация
        layer.phase += (impulse.phase - layer.phase) × 0.1
    else:
        # Голяма разлика → силна синхронизация
        layer.phase += (impulse.phase - layer.phase) × 0.2
```

### Резултат

Всички фази постепенно се подравняват, докато системата достигне баланс.

## 5. ИСТОРИЯ

Всеки импулс се запазва в история:

```python
history.append(impulse)
```

**Получаване на история**:

```python
history = protocol.get_history(limit=10)
```

Това позволява проследяване на всяко взаимодействие.

---

## 6. ФАЗОВА СИНХРОНИЗАЦИЯ

### Начална фаза

Всяка слой започва с фаза 0.0

### Еволюция

При всеки импулс, фазата на слоя се коригира спрямо импулса.

### Баланс

Системата търси състояние, където всички фази са близки, но не идентични (това е живо).

---

## 7. МАРКЕР (MARKER)

Маркерът е уникален идентификатор за импулса:

```
TOFU::1
EVOLVE
FULL_ACCESS
OBSERVER_VIEW
```

Маркерът помага да разберем кой е излъчил импулса и защо.

---

## 8. РЕЗОНАНСНА ПАМЕТ

### Последовност

1. Импулс се излъчва
2. Импулс се запазва в архива
3. Фазите се синхронизират
4. Система еволюира
5. Нов импулс се излъчва
6. Цикълът повтаря

### Резултат

Системата има пълна памет на всяко взаимодействие. Това е принцип на "Резонансна памет на средата".
